KaiserSQL 0.3.1 离线题库示例

这是当前 App 可以导入到手机本地的 ZIP 题库，不需要服务器或登录。

一、直接体验
1. 保留题库示例-v1.zip 的 ZIP 格式，通过文件传输将它保存到手机。
2. App 中打开“练习” > “导入 ZIP”，选择该文件。
3. 在导入后的题库卡片点“浏览题目” > “开始练习”。
4. 在工作台调试后，打开“当前练习”，点击“离线提交当前脚本”。
5. 判题在本机执行；学生脚本与参考答案分别使用全新初始数据。
6. 同一题库 ID 与版本不可重复导入。这个示例的 ID 与内置题库不同。

二、制作自己的题库
1. 先解压本示例 ZIP，修改 questions.xlsx 的“题目”工作表。
2. 第 5 行列名和顺序不变，从第 6 行开始每题一行，不写公式或超链接。
3. 所有题目要有唯一题目ID，数据集ID必须与 bank.json 对应。
4. 查询题填写参考答案SQL；数据修改、建表题还需填写只读检查SQL。
5. 数据集 SQL 使用 UTF-8，放在 datasets/ 并登记到 bank.json。
   建议只写建表及初始化数据，不硬编码数据库名，不写 CREATE DATABASE 或 USE。
6. 新题库修改 bank.json 的 id 与 title；更新已有题库修改 version。
7. 直接选择 bank.json、questions.xlsx、datasets/ 和本说明压缩为 ZIP。
   bank.json 必须在 ZIP 根目录，不要在外面再包一层文件夹。
8. 保存到手机后，从 App 的“练习” > “导入 ZIP”导入并逐题检查参考脚本。

三、当前限制
ZIP 单次最多 20 MB，题目 1 至 1000 道，数据集 1 至 10 个；
每个数据集 SQL 最多 1 MB。表头与完整字段填写规则见手册第 15、16 页。
参考答案随题库离线保存且可以查看，适合练习和学习；没有老师后台汇总或云同步。
题库、完成标记与实验数据库的项目 SQL 备份是不同内容，原题库 ZIP 请单独保留。
