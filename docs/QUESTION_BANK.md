# 制作和导入离线题库

先修改 examples/question-bank/题库模板.xlsx，或解压该目录的题库示例-v1.zip。手机端进入“练习” > “导入 ZIP”。

ZIP 根目录必须直接包含：

```text
bank.json
questions.xlsx
datasets/
  ecommerce.sql
```

bank.json 示例、13 列字段规则、查询题和修改题判题方式在完整手册第 15、16 页。题目工作表叫“题目”，第 5 行是列名，从第 6 行开始每题一行。

列顺序必须完全一致：题目ID、数据集ID、题型、标题、难度、知识点、题干、起始SQL、参考答案SQL、检查SQL、要求排序、提示、解析。

题型填写“查询”“数据修改”或“建表”；要求排序填写“是”或“否”。所有题目都需要参考答案 SQL，修改和建表题还需要只读检查 SQL。数据集以 UTF-8 SQL 初始化，建议不写 CREATE DATABASE 或 USE，不硬编码判题数据库名。

同一题库 ID 和版本不可重复导入；更新题库时修改 version，新建题库时修改 id 和 title。不要在 ZIP 外再套一层文件夹。

单次 ZIP 最大 20 MB，1 至 1000 道题、1 至 10 个数据集；单数据集 SQL 最大 1 MB。拒绝公式、超链接、重复 ID、缺失数据集和不安全文件路径。判题比较列数量、位置、值、重复行及需要的行顺序，不要求列别名相同。

完整说明：examples/question-bank/题库制作说明.txt。参考答案保存在题库内且 App 可查看；题库功能适合学习练习，没有云端考试后台。
